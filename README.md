# JANN — one-page site (draft)

Simple bilingual (PL/EN) business-card page for DJ **JANN** (Jan Syczewski, Szczecin).

- Melodic house / tech house / techno
- Embedded YouTube sets (youtube-nocookie)
- SoundCloud + YouTube links
- Booking contact via manager (`orda.bling@gmail.com`)
- Phone / Instagram: placeholders in `window.JANN_CONFIG` at the top of `index.html` (hidden while empty)

## Status

**Draft / wersja robocza.** Deployed with `noindex`. Do not treat as final brand site until Janek (Jan Syczewski) confirms.

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080 --directory .
```

## Render

Free static site. Blueprint: `render.yaml` (`name: jann-dj`, `staticPublishPath: ./`).

